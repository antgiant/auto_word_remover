# replacement_pool.txt  --  a flat, UN-mapped bucket of replacement words/
# phrases for --method replace's pool mode (--replace-pool)
#
# One entry per line. '#' starts a comment. Unlike replacements.txt (mapped
# mode), there is NO "surface => replacement" relationship here at all -
# every flagged occurrence in the file, regardless of which word it
# actually was, draws a few candidates at random from this whole list (see
# word_replace.select_pool_candidates). That's the point of pool mode: a
# listener can't work backward from "biscuits" to "that was the f-word"
# the way they could if biscuits only ever replaced one specific word.
#
# This starter list is a small, directly-sourced set of Bluey's own
# family-friendly exclamations/euphemisms, not a comprehensive catalogue -
# confirmed via web search 2026-10-21, not independently fact-checked
# against every episode:
#   - "Biscuits", "Cheese and jam", "Beans on toast" are Bandit's own
#     go-to exclamations in place of swearing (incl. a Bluey Father's Day
#     promotional clip where he walks through exactly this).
#   - "Fluffy" is Chilli's family's chosen euphemism for a fart ("Family
#     Meeting") - an "off-limits thing" euphemism rather than a swear
#     substitute, but fits this bucket the same way.
# Add more of your own as you find them - this is deliberately a seed, not
# a finished list, same as replacements.txt's own starter content.

biscuits
cheese and jam
beans on toast
fluffy
