# replacements.txt  --  word/phrase -> non-profane replacement word(s), for
# --method replace
#
# One entry per line. '#' starts a comment.
#   surface1, surface2, ... => repl1, repl2, ...
# - LEFT: literal, case-insensitive surface forms exactly as they appear in
#   a flagged hit's matched text - inflections (fuck/fucking/fucked/...)
#   are spelled out explicitly, there is no morphology/stemming here. A
#   multi-word phrase works the same way (see the irreverence.txt section
#   below) - the whole phrase is one key, not split into per-word lookups.
# - RIGHT: one or more candidate replacement words/phrases, in your own
#   priority order (used as a tiebreak when two candidates are otherwise
#   equally good - see word_replace.select_replacement_words, which picks
#   whichever candidate's length is closest to the original word's).
# - A lookup MISS (surface form not listed here) degrades gracefully: that
#   one occurrence falls back to the existing mute behaviour for just its
#   own span - never a hard failure, never silently dropped.
# - Not every open-ended wordlist pattern can be covered here. irreverence.txt
#   detects some phrases via regex wildcards (e.g. "christ on a \w+" matches
#   infinitely many literal variants) - a hand-authored exact-phrase table
#   can only list the common instances you actually expect. An unlisted
#   variant is a lookup miss -> mute, same as any other miss.
#
# This is a STARTER list, not a finished one - it's meant to be rewritten.
# Pick your own replacement words freely (silly, deadpan, in-joke, whatever
# you want); nothing here needs to read as a serious "TV edit" word choice.
# Re-read every run; tune freely.
